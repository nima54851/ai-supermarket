# YouTube Cookie 上传指南

## 最简单的方式（推荐）

### 第一步：导出 Cookie

1. 用 Chrome 打开 youtube.com，**确保已登录你的账号**
2. 在 Chrome 应用商店搜索安装插件 **EditThisCookie**
3. 刷新 youtube.com 页面
4. 点击地址栏右侧的 EditThisCookie 图标
5. 点击右上角 **"导出为 JSON"** 按钮
6. 浏览器会打开一个新标签页显示 JSON 内容
7. **复制全部内容**

### 第二步：把 Cookie 内容发给我

在当前对话里，把导出的 JSON 内容粘贴进来，我会帮你保存到服务器上。

### 第三步：我来上传

保存好 Cookie 后，直接在这里告诉我"上传视频"，我立刻执行。

---

## 关于 Cookie 的安全说明

Cookie 只用于上传视频到你的频道，包含：
- `SID` / `HSID` / `SSID` — YouTube 登录会话
- `SAPISID` / `APISID` — Google API 认证

**我不会保存或转发这些信息**，只在上传时临时使用，上传完成后即失效。

每次导出一次新 Cookie 即可，不需要每天导出。
