# 🚀 CoursePay - 完整的课程销售平台

## 🎯 平台简介
这是一个完整的、可直接使用的课程销售平台，专为快速收款设计。

## ✨ 主要功能
- ✅ 课程展示和销售
- ✅ PayPal直接收款 (账户: yinanzo@hotmail.com)
- ✅ 订单管理
- ✅ 用户系统
- ✅ 响应式设计
- ✅ 移动端适配

## 💰 收款流程
1. **学生**: 选择课程 → 复制收款账户 → PayPal转账
2. **管理员**: 查看PayPal收款 → 发送课程链接 → 管理订单
3. **平台**: 自动记录订单 → 提供管理界面 → 统计分析
